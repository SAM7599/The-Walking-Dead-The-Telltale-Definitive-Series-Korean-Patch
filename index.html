패치는 이 사이트의 버튼이나 GitHub 저장소의 Releases 에서만 받아 주세요. 다른 곳에서 받은 파일은 사용하지 마세요.

설치 전에 꼭 읽어 주세요

1. 일부 자막이 잘려 보일 수 있습니다.
한국어는 영어보다 글자 폭이 넓고 문장이 길어지는 경우가 많아, 일부 자막은 마지막 줄이 화면 아래쪽에서 잘려 보일 수 있습니다. 읽을 수 있는 상태이지만 이런 부분이 곳곳에 섞여 있을 수 있습니다. 너무 많이 잘려 읽을 수 없는 자막은 GitHub Issues 로 제보해 주세요.
2. 자막 크기 설정(크게 / 보통 / 작게)을 바꿔도 크기가 거의 변하지 않습니다.
이 패치는 중국어 간체 칸의 글꼴과 글자를 한국어로 바꿔 넣는 방식이라, 게임의 크기 설정이 한국어 글꼴에 제대로 적용되지 않는 것으로 보입니다. 자막 크기는 읽기 편한 기본 크기에 맞춰 두었습니다.
3. 글꼴을 바꿨습니다.
처음에는 선명한 고딕체였지만 가독성이 낮아, 붓글씨 느낌의 East Sea Dokdo 글꼴로 바꿨습니다.
4. 설치 후 언어 설정 > 표시 텍스트 를 中文 (简体) 로 선택해 주세요.
5. 잔인한 장면과 광과민성 주의
좀비에게 물어뜯기는 장면, 신체 훼손, 폭력, 아동 관련 폭력, 욕설, 약물, 자살 등 불쾌할 수 있는 내용이 있습니다. (만 18세 이상 권장) 총 섬광, 폭발, 번개, 깜빡이는 조명 등 빛이 번쩍이는 장면도 나오니, 어지럽거나 몸이 불편하면 바로 플레이를 멈추세요.
  • 스팀 업데이트나 파일 무결성 검사를 하면 패치가 사라질 수 있습니다. 이 경우 다시 설치해 주세요.
  • 전체가 기계번역이라 어색한 문장이나 오역이 있을 수 있습니다.
  • 게임 저장 데이터는 건드리지 않습니다.
  • 서명되지 않은 프로그램이라 윈도우 SmartScreen 경고나 일부 백신(V3, 알약 등)의 오탐이 나올 수 있습니다. 해결 방법은 아래 자주 묻는 질문을 확인해 주세요.

설치 방법

  1. 압축 파일을 받아 비밀번호 0000 으로 풉니다.
  2. 게임이 꺼져 있는지 확인합니다. 켜져 있으면 프로그램이 종료를 안내합니다.
  3. TWD_KR_Patch.bat 를 실행합니다.
  4. 처음에 나오는 주의 안내(잔인한 장면, 광과민성)를 읽고 Enter 키를 누릅니다.
  5. 안내 화면에서 Y 를 누르고 1번(설치) 을 선택합니다.
  6. 설치가 끝나면 게임을 실행하고 언어 설정 > 표시 텍스트 를 中文 (简体) (간체)로 바꿉니다.
中文 (繁體) (번체)를 고르면 한국어가 나오지 않고 영어로 보입니다. 반드시 간체를 선택해 주세요.

제거: TWD_KR_Patch.bat 를 다시 실행하고 2번(제거) 을 선택하면 원본으로 복구됩니다. 원본 백업은 게임 폴더의 Archives\KR_Backup 에 있습니다.

  1. 스팀덱을 데스크톱 모드 로 전환합니다. (스팀 버튼 > 전원 > 데스크톱으로 전환)
  2. 데스크톱 모드의 브라우저로 SteamDeck 압축 파일을 받습니다.
  3. 받은 파일을 우클릭해 "여기에 압축 풀기"를 선택하고 비밀번호 0000 을 입력합니다.
  4. 게임이 꺼져 있는지 확인합니다.
  5. TWD_KR_Patch_Linux.sh 를 더블클릭하고, 실행 방법을 묻는 창이 뜨면 "터미널에서 실행"을 선택합니다.
  6. 처음에 나오는 주의 안내를 읽고 Enter 키를 누릅니다.
  7. Y 를 누르고 1번(설치) 을 선택합니다. 게임 폴더는 자동으로 찾으며 SD 카드에 설치한 게임도 찾아 줍니다.
  8. 게임 모드로 돌아와 게임을 실행하고 언어 설정 > 표시 텍스트 를 中文 (简体) 로 바꿉니다.
실행되지 않으면 파일을 우클릭하고 속성 > 권한 에서 "실행 가능"을 체크한 뒤 다시 시도해 주세요.

제거: 같은 파일을 다시 실행해 2번(제거) 을 선택하세요.

자주 묻는 질문

설치했는데 글자가 전부 네모로 보여요.
표시 텍스트를 中文 (繁體) (번체)로 선택하셨을 가능성이 가장 큽니다. 中文 (简体) (간체)로 바꿔 주세요.
언어 설정에 한국어가 없어요. 中文 (简体) 가 한국어가 맞나요?
정상입니다. 이 패치는 게임의 중국어 간체 칸을 한국어로 바꿔 넣는 방식이라, 표시 텍스트에서 中文 (简体) 를 고르시면 한국어로 나옵니다. 언어 이름은 계속 中文 (简体) 로 보이지만 실제 글자는 한국어입니다.
언어 이름을 "한국어" 로 보이게 할 수는 없나요?
그렇게 하고 싶었지만 불가능했습니다. 언어 목록의 "中文 (简体)" 라는 이름은 게임 데이터 파일이 아니라 게임 실행 파일(WDC.exe)이 직접 만들어 보여 주는 것이라 패치로 바꿀 수 없습니다. 실행 파일은 수정하면 게임이 실행되지 않거나 스팀 업데이트 때 되돌려질 수 있어 건드리지 않았습니다.
영어 등 다른 언어를 고르면 왜 깨지나요?
이 패치는 간체 칸뿐 아니라 영어 칸과 다른 언어 칸에도 한국어를 넣어 두었습니다. 그래서 간체가 아닌 언어를 고르면 한국어 글꼴이 적용되지 않아 네모나 깨진 글자로 보일 수 있습니다. 반드시 中文 (简体) 를 선택해 주세요. 언어 설정 메뉴만은 영어로 읽히게 두고 "Select 中文 (简体)" 안내를 넣어 두었습니다.
클렘의 말투가 사람마다 다른데 맞나요?
의도한 것입니다. 클렘은 리와 오래 알고 지낸 사람(에이제이, 케니 등)에게는 반말을, 처음 만났거나 만난 지 얼마 안 된 사람에게는 존댓말을 씁니다. 에피소드가 진행되며 가까워진 사람에게는 점차 반말로 바뀝니다. 자동으로 정리한 부분이 많아 어색한 곳이 있을 수 있으니 발견하시면 Issues 에 알려 주세요.
설치할 때 "게임 버전이 패치 제작 버전과 다를 수 있습니다" 라고 떠요.
게임 파일 크기가 패치 제작 때와 다르다는 안내입니다. 이미 다른 패치가 깔려 있거나 게임 버전이 다를 때 나옵니다. 패치 제거 후 스팀에서 게임 파일 무결성 검사를 하고 다시 설치해 보세요.
백신에서 바이러스라고 나오고 설치가 안 돼요.
오탐입니다. 개인이 만든 서명되지 않은 프로그램이라 백신이 잘못 판단하는 경우가 있습니다.
  1. 압축 파일 안의 SHA256.txt 값과 받은 파일의 해시 값이 같은지 확인합니다.
  2. 백신(V3, 알약, 윈도우 보안 등)의 검사 예외에 패치를 풀어 둔 폴더를 추가합니다.
  3. 이미 격리되었다면 격리소에서 복원한 뒤 다시 압축을 풉니다.
  4. SmartScreen 창이 뜨면 "추가 정보" > "실행"을 선택합니다.
  5. 설치가 끝난 뒤에는 예외 등록을 지우셔도 됩니다.
업데이트 후 영어(또는 중국어)로 돌아왔어요.
스팀 업데이트나 무결성 검사로 파일이 원래대로 돌아간 것입니다. 패치를 다시 설치해 주세요.
그래도 해결이 안 돼요.

  • 가능하면 영상 설명란이나 방송 소개에 "한국어 패치/기계번역: SAM_7599" 와 이 사이트 주소를 남겨 주시면 감사하겠습니다. (의무는 아닙니다.)
  • 패치 파일을 다른 곳에 다시 올려 배포하거나 판매하는 것은 허용하지 않습니다.
  • 게임 화면의 방송, 영상 공개, 수익 창출 가능 여부는 게임의 원 권리자와 방송 플랫폼의 정책을 따릅니다. 이 패치는 그 권리를 대신 허락하지 않으며, 법적 조언이 아닙니다. 방송 전에 각 정책을 직접 확인해 주세요.
