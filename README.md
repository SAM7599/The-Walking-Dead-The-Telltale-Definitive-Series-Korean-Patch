# 워킹 데드: 텔테일 데피니티브 시리즈 한국어 패치

**The Walking Dead: The Telltale Definitive Series** 한국어 패치 (기계번역)

<img width="1672" height="941" alt="40ebca40-96ea-4a95-bb06-281dbdefe7fc" src="https://github.com/user-attachments/assets/48b8bfc3-edb3-4354-bd90-1c5e21f506c8" />


시즌 1~4, 400일, 미셸 미니시리즈 전체를 한국어로 즐길 수 있는 비공식 팬 패치입니다.
기계번역을 바탕으로 인물별 말투와 호칭을 직접 다듬었습니다.
설치 프로그램 하나로 설치와 제거가 모두 가능하고, 게임 폴더도 자동으로 찾아 줍니다.

## 패치 정보

| 항목 | 내용 |
| --- | --- |
| 대상 게임 | The Walking Dead: The Telltale Definitive Series (스팀) |
| 번역 방식 | 기계번역 후 말투와 호칭 수정 |
| 제작자 | SAM_7599 |
| 압축 비밀번호 | 0000 |

## 적용 범위

- 시즌 1 ~ 시즌 4, 400일, 미셸 미니시리즈
- 대사, 선택지, 메뉴, 통계 화면, 크레딧, 스토리 알림
- 한글 글꼴 (자막은 붓글씨 느낌의 East Sea Dokdo 글꼴)

## 다운로드

[Releases](../../releases) 에서 최신 압축 파일을 받아 주세요. 윈도우는 일반 압축 파일, 스팀덱 / 스팀머신은 SteamDeck 이 붙은 압축 파일입니다.
패치는 이 저장소의 Releases 에서만 받아 주세요. 다른 곳에서 받은 파일은 사용하지 마세요.

## 설치 방법

1. 압축 파일을 받아 비밀번호 `0000` 으로 풉니다.
2. 게임이 꺼져 있는지 확인합니다. 켜져 있으면 프로그램이 종료를 안내합니다.
3. `TWD_KR_Patch.bat` 를 실행합니다.
4. 안내 화면에서 `Y` 를 누르고 1번(설치)을 선택합니다.
5. 설치가 끝나면 게임을 실행합니다.
6. 게임의 언어 설정 > 표시 텍스트 를 **中文 (简体)** (간체)로 바꿉니다.

- 한국어 메뉴가 따로 없어서 중국어 간체 칸을 한국어로 바꿔 넣는 방식입니다.
- **中文 (繁體)** (번체)를 고르면 한국어가 나오지 않고 영어로 보입니다. 반드시 간체를 선택해 주세요.
- 처음 실행하면 메인 메뉴와 크레딧에 "한국어 패치(기계번역) - SAM_7599" 문구가 표시됩니다.

## 설치 방법 (스팀덱 / 스팀머신)

스팀덱과 스팀머신은 윈도우용과 파일이 다릅니다. Releases 에서 **SteamDeck** 이 붙은 압축 파일을 따로 받아 주세요.

1. 스팀덱을 **데스크톱 모드**로 전환합니다. (스팀 버튼 > 전원 > 데스크톱으로 전환)
2. 데스크톱 모드의 브라우저로 SteamDeck 압축 파일을 받습니다.
3. 받은 파일을 우클릭하고 "여기에 압축 풀기"를 선택한 뒤, 비밀번호 `0000` 을 입력합니다.
4. 게임이 꺼져 있는지 확인합니다.
5. 풀린 폴더에서 `TWD_KR_Patch_Linux.sh` 를 더블클릭합니다. 실행 방법을 묻는 창이 뜨면 "터미널에서 실행"(Execute in Terminal)을 선택합니다. 실행되지 않으면 파일을 우클릭하고 속성 > 권한에서 "실행 가능" 을 체크한 뒤 다시 시도합니다.
6. 안내 화면에서 `Y` 를 누르고 1번(설치)을 선택합니다. 게임 폴더는 자동으로 찾으며, SD 카드에 설치한 게임도 찾아 줍니다.
7. 설치가 끝나면 게임 모드로 돌아와 게임을 실행하고, 언어 설정 > 표시 텍스트 를 **中文 (简体)** (간체)로 바꿉니다.

- 제거는 같은 파일을 다시 실행해 2번(제거)을 선택하면 됩니다.
- 원본 백업은 게임 폴더의 `Archives/KR_Backup` 에 저장됩니다.

## 제거 방법

`TWD_KR_Patch.bat` 를 다시 실행하고 2번(제거)을 선택하면 원본 상태로 복구됩니다.
원본 백업은 게임 폴더의 `Archives\KR_Backup` 에 저장됩니다.

## 주의 사항

- 전체가 기계번역이라 어색한 문장이나 오역이 있을 수 있습니다.
- 스팀 업데이트나 파일 무결성 검사를 하면 패치가 사라질 수 있습니다. 이 경우 다시 설치해 주세요.
- 게임 저장 데이터는 건드리지 않습니다.
- 게임 버전이 패치 제작 버전과 달라도 설치는 진행되지만, 일부 문장이 번역되지 않을 수 있습니다.
- 서명되지 않은 프로그램이라 윈도우 SmartScreen 경고나 일부 백신(V3, 알약 등)의 바이러스 오탐이 나올 수 있습니다. 설치 프로그램은 게임 폴더의 파일만 바꾸며, 그 외에는 아무것도 하지 않습니다. 같이 들어 있는 `SHA256.txt` 의 값과 받은 파일의 해시 값이 같은지 확인한 뒤 실행해 주세요. 차단될 때의 해결 방법은 아래 자주 묻는 질문을 확인해 주세요.

## 자주 묻는 질문

### Q: **설치했는데 글자가 전부 네모로 보여요.**
A: 표시 텍스트를 中文 (繁體) (번체)로 선택하셨을 가능성이 가장 큽니다. 中文 (简体) (간체)로 바꿔 주세요.

### Q: **언어 설정에 한국어가 없어요.**
A: 정상입니다. 표시 텍스트에서 中文 (简体) 를 고르시면 한국어로 나옵니다.

### Q: **설치할 때 "게임 버전이 패치 제작 버전과 다를 수 있습니다" 라고 떠요.**
A: 게임 파일 크기가 패치 제작 때와 다르다는 안내입니다. 이미 다른 패치가 깔려 있거나 게임 버전이 다를 때 나옵니다. 패치 제거 후 스팀에서 게임 파일 무결성 검사를 하고 다시 설치해 보세요.

### Q: 백신에서 바이러스라고 나오고 설치가 안 돼요. 
A: 오탐입니다. 개인이 만든 서명되지 않은 프로그램이라 백신이 위험한 파일로 잘못 판단하는 경우가 있습니다. 아래 순서로 진행해 주세요.

1. 압축 파일 안의 `SHA256.txt` 값과 받은 파일의 해시 값이 같은지 확인합니다. 같으면 올린 파일 그대로입니다.
2. 백신(V3, 알약, 윈도우 보안 등)의 검사 예외 설정에 패치를 풀어 둔 폴더를 추가합니다.
3. 이미 격리되었다면 백신의 격리소에서 파일을 복원한 뒤 다시 압축을 풉니다.
4. 윈도우 SmartScreen 창이 뜨면 "추가 정보" > "실행"을 선택합니다.
5. 설치가 끝난 뒤에는 예외 등록을 지우셔도 됩니다.

### Q: **그래도 해결이 안 돼요.**
A: 게임 폴더에 생기는 `KR_패치_점검결과.txt` 파일 내용을 함께 알려 주세요.

### Q: **업데이트 후 영어(또는 중국어)로 돌아왔어요.**
A: 스팀 업데이트나 무결성 검사로 파일이 원래대로 돌아간 것입니다. 패치를 다시 설치해 주세요.

### Q: **어색한 번역을 발견했어요.**
A: Issues 에 장면과 문장을 알려 주시면 다음 버전에 반영하겠습니다.

## 면책

이 패치는 비공식 팬 제작물이며, 원 저작권은 각 권리자에게 있습니다.
게임 본편은 포함되어 있지 않으며, 정식으로 구입한 게임에만 적용해 주세요.
