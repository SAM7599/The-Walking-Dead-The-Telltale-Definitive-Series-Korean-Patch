## 소개

게임에 한국어가 없어서, 전체 텍스트를 한국어로 번역해 적용하는 패치입니다.
대사, 메뉴, 선택지, 크레딧까지 약 6만 줄을 번역했고 한글이 깨지지 않도록 폰트도 함께 교체합니다.

게임에 한국어 항목이 따로 없기 때문에 **중국어 간체 칸에 한국어를 넣는 방식**입니다.
설치 후 언어를 `简体中文`으로 선택하면 한국어로 표시됩니다.

## 주요 기능

- 시즌 1, 2, 3(새로운 개척지), 4(파이널 시즌), 400일, 미숀 전체 번역
- 한글 폰트 적용 (Noto Sans CJK)
- 설치 프로그램 하나로 설치와 제거 모두 가능
- 설치 전 원본 파일 자동 백업, 설치 후 검증
- 스팀 게임 폴더 자동 탐색
- 게임 버전이 달라도 설치 진행

## 설치 방법

1. 릴리스에서 zip 파일을 받습니다.
2. 압축 비밀번호 `0000` 으로 압축을 풉니다.
3. **게임을 완전히 종료**합니다.
4. `TWD_KR_Patch.exe` 를 실행합니다.
5. 안내 화면에서 `Y` 를 누르고 `1` (설치)을 선택합니다.
6. 설치가 끝나면 게임을 실행합니다.
7. 설정의 언어를 **简体中文** 으로 선택합니다.

처음 실행하면 메인 메뉴와 크레딧에 `한국어 패치(기계번역) - SAM_7599` 문구가 표시됩니다.

## 제거 방법

`TWD_KR_Patch.exe` 를 다시 실행하고 `2` (제거)를 선택하면 원본 상태로 복구됩니다.
원본 백업은 게임 폴더의 `Archives\KR_Backup` 에 저장됩니다.

## 주의 사항

- 스팀에서 게임이 업데이트되거나 파일 무결성 검사를 하면 패치가 사라질 수 있습니다. 이 경우 다시 설치하면 됩니다.
- 전체가 기계번역이라 어색한 문장이나 오역이 있을 수 있습니다.
- 게임 저장 데이터는 건드리지 않습니다.
- 게임 버전이 패치 제작 버전과 달라도 설치는 진행되지만, 일부 문장이 번역되지 않을 수 있습니다.

## 면책

이 패치는 비공식 팬 제작물이며, 원 저작권은 각 권리자에게 있습니다.
게임 본편은 포함되어 있지 않으며, 정식으로 구입한 게임에만 적용하세요.
