## 설치 방법 (윈도우)

1. 압축 파일을 받아 비밀번호 `0000` 으로 풉니다.
2. 게임이 꺼져 있는지 확인합니다.
3. `TWD_KR_Patch.bat` 를 실행합니다.
4. 처음에 나오는 주의 안내(잔인한 장면, 광과민성)를 읽고 Enter 키를 누릅니다.
5. 안내 화면에서 `Y` 를 누르고 **1번(설치)** 을 선택합니다.
6. 게임을 실행하고 **언어 설정 > 표시 텍스트** 를 **中文 (简体)** 로 바꿉니다.

처음 실행하면 시작 화면, 메인 메뉴, 크레딧에 "한국어 패치/기계번역: SAM_7599" 문구가 표시됩니다.

> [!NOTE]
> **🔄 게임을 켤 때 새 패치를 자동으로 확인합니다. (윈도우)**
> 설치할 때 스팀의 게임 실행 옵션이 자동으로 설정됩니다. 이후 게임을 켤 때 새 패치가 있으면 팝업으로 물어보고, 동의하면 다운로드부터 설치까지 자동으로 진행합니다.
> 스팀이 켜져 있으면 자동 설정이 안 되므로, 설치 화면에 나오는 한 줄을 스팀 > 게임 우클릭 > 속성 > 실행 옵션 칸에 붙여넣어 주세요.
> 게임을 켜면 작업표시줄에 "TWD KR Launcher" 창이 함께 떠 있을 수 있습니다. 정상이며, 닫아도 게임은 꺼지지 않습니다.

## 설치 방법 (스팀덱 / 스팀머신)

스팀덱과 스팀머신은 윈도우용과 파일이 다릅니다. Releases 에서 **SteamDeck** 이 붙은 압축 파일을 따로 받아 주세요.

1. 스팀덱을 **데스크톱 모드** 로 전환합니다. (스팀 버튼 > 전원 > 데스크톱으로 전환)
2. 데스크톱 모드의 브라우저로 SteamDeck 압축 파일을 받습니다.
3. 받은 파일을 우클릭하고 "여기에 압축 풀기"를 선택한 뒤, 비밀번호 `0000` 을 입력합니다.
4. 게임이 꺼져 있는지 확인합니다.
5. 풀린 폴더에서 `TWD_KR_Patch_Linux.sh` 를 더블클릭하고, 실행 방법을 묻는 창이 뜨면 "터미널에서 실행"(Execute in Terminal)을 선택합니다.
6. 주의 안내를 읽고 Enter 키를 누른 뒤, `Y` 를 누르고 **1번(설치)** 을 선택합니다. 게임 폴더는 자동으로 찾으며, SD 카드에 설치한 게임도 찾아 줍니다.
7. 게임 모드로 돌아와 게임을 실행하고, **언어 설정 > 표시 텍스트** 를 **中文 (简体)** 로 바꿉니다.

> [!TIP]
> 5번에서 실행되지 않으면 파일을 우클릭하고 **속성 > 권한** 에서 "실행 가능"을 체크한 뒤 다시 시도해 주세요.

## 제거 방법

설치할 때 쓴 파일(`TWD_KR_Patch.bat` 또는 `TWD_KR_Patch_Linux.sh`)을 다시 실행하고 **2번(제거)** 을 선택하면 원본 상태로 복구됩니다.
원본 백업은 게임 폴더의 `Archives\KR_Backup` 에 저장됩니다.

## 주의 사항

> [!WARNING]
> **⚠️ 잔인한 장면과 빛 자극에 대한 안내**
> 이 게임에는 좀비에게 물어뜯기는 장면, 신체 훼손, 폭력, 아동 관련 폭력, 욕설, 약물, 자살 등 잔인하고 불쾌할 수 있는 내용이 포함되어 있습니다. (만 18세 이상 권장)
> 총 섬광, 폭발, 번개, 깜빡이는 조명 등 빛이 번쩍이는 장면도 나옵니다. 빛 자극에 예민하신 분은 주의하시고, 어지럽거나 몸이 불편하면 바로 플레이를 멈추세요.
>
> 원래 게임에는 이런 안내가 없어서 설치 프로그램에 같은 내용을 넣었습니다. 설치 프로그램의 안내는 참고용일 뿐이며, 플레이 중 생기는 건강상의 문제(정신적 충격, 불쾌감, 광과민성 증상 등)는 패치 제작자나 설치 프로그램이 대신 책임지지 않습니다. 본인의 상태를 확인하고 플레이해 주세요.

**패치 사용 시 알아 두세요**

- 전체가 기계번역이라 어색한 문장이나 오역이 있을 수 있습니다.
- 한국어는 영어보다 글자 폭이 넓고 문장이 길어서, 일부 자막은 마지막 줄이 화면 아래에서 잘려 보일 수 있습니다.
- 게임의 자막 크기 설정(크게 / 보통 / 작게)을 바꿔도 크기가 거의 변하지 않습니다. 자막 크기는 기본으로 읽기 편한 크기에 맞춰 두었습니다.
- 스팀 업데이트나 파일 무결성 검사를 하면 패치가 사라질 수 있습니다. 이 경우 다시 설치해 주세요.
- 게임 저장 데이터는 건드리지 않습니다.
- 게임 버전이 패치 제작 버전과 달라도 설치는 진행되지만, 일부 문장이 번역되지 않을 수 있습니다.
- 서명되지 않은 프로그램이라 윈도우 SmartScreen 경고나 일부 백신(V3, 알약 등)의 오탐이 나올 수 있습니다. 설치 프로그램은 게임 폴더의 파일만 바꿉니다. 같이 들어 있는 `SHA256.txt` 의 값과 받은 파일의 해시 값이 같은지 확인한 뒤 실행해 주세요. 해결 방법은 아래 자주 묻는 질문을 확인해 주세요.

## 이슈 제보 안내

Issues 에는 아래 세 가지만 제보해 주세요.

1. **자막이 잘려 보이는 문제** (읽을 수 없을 정도인 경우)
2. **어색한 번역**
3. **자막 기본 크기**가 너무 작거나 크게 느껴지는 경우

이 밖의 요청(글꼴 변경, 기능 추가 등)은 지금은 반영하기 어렵습니다. 몇 시즌 몇 에피소드의 어느 장면인지와 스크린샷, 문장을 함께 적어 주시면 빠르게 확인할 수 있습니다.

## 방송 및 영상 사용

이 게임은 10년 전부터 유튜브 영상과 라이브 방송으로 널리 공개되어 왔습니다. 한국어 패치를 적용한 화면도 같은 기준으로 **라이브 방송, 수익 창출, 동영상 제작을 자유롭게 하셔도 됩니다.** 따로 허락을 받으실 필요는 없습니다.

- 가능하면 영상 설명란이나 방송 소개에 "한국어 패치/기계번역: SAM_7599" 와 이 저장소 주소를 남겨 주시면 감사하겠습니다. (의무는 아닙니다.)
- 패치 파일을 다른 곳에 다시 올려 배포하거나 판매하는 것은 허용하지 않습니다.

<details>
<summary><b>언어 설정에 한국어가 없어요. 中文 (简体) 가 맞나요?</b></summary>

<br>

정상입니다. 이 패치는 게임의 중국어 간체 칸을 한국어로 바꿔 넣는 방식이라, 언어 이름은 계속 中文 (简体) 로 보이지만 실제 글자는 한국어입니다.

언어 이름을 "한국어"로 바꾸는 것은 불가능했습니다. 이름은 게임 데이터가 아니라 실행 파일(WDC.exe)이 직접 만들어 보여 주는 것이고, 실행 파일은 수정하면 게임이 실행되지 않거나 스팀 업데이트 때 되돌려질 수 있어 건드리지 않았습니다.

</details>

<details>
<summary><b>다른 언어(영어 등)를 고르면 어떻게 되나요?</b></summary>

<br>

게임은 간체를 골라도 일부 자막과 문구를 영어 칸 등 다른 칸에서 읽어 오는 경우가 있어서, 이 패치는 간체 칸뿐 아니라 영어 칸과 다른 언어 칸에도 한국어를 넣어 두었습니다. 덕분에 어느 칸에서 읽어 와도 한국어로 나옵니다.

다만 영어 등 다른 언어를 직접 선택하면 한국어 글꼴이 없어 네모나 깨진 글자로 보일 수 있습니다. 언어 설정 메뉴만은 영어로 읽히게 두고 "Select 中文 (简体)" 안내를 넣어, 깨진 상태에서도 언어를 되돌릴 수 있게 했습니다. 반드시 **中文 (简体)** 를 선택해 주세요.

</details>

<details>
<summary><b>클렘의 말투가 사람마다 다른데 맞나요?</b></summary>

<br>

의도한 것입니다. 클렘은 리와 오래 알고 지낸 사람(에이제이, 케니 등)에게는 반말을, 처음 만났거나 만난 지 얼마 안 된 사람에게는 존댓말을 씁니다. 에피소드가 진행되며 가까워진 사람에게는 점점 반말로 바뀝니다. 자동으로 정리한 부분이 많아 어색한 곳이 있을 수 있으니, 발견하시면 Issues 에 알려 주세요.

</details>

<summary><b>설치할 때 "게임 버전이 패치 제작 버전과 다를 수 있습니다" 라고 떠요.</b></summary>

<br>

게임 파일 크기가 패치 제작 때와 다르다는 안내입니다. 이미 다른 패치가 깔려 있거나 게임 버전이 다를 때 나옵니다. 패치 제거 후 스팀에서 게임 파일 무결성 검사를 하고 다시 설치해 보세요.

<details>
<summary><b>백신에서 바이러스라고 나오고 설치가 안 돼요.</b></summary>

<br>

오탐입니다. 개인이 만든 서명되지 않은 프로그램이라 백신이 위험한 파일로 잘못 판단하는 경우가 있습니다. 아래 순서로 진행해 주세요.

1. 압축 파일 안의 `SHA256.txt` 값과 `TWD_KR_Patch.bat` 파일의 해시 값이 같은지 확인합니다. 같으면 올린 파일 그대로입니다. (릴리스 페이지의 해시와 다른 이유는 아래 질문을 확인해 주세요.)
2. 백신(V3, 알약, 윈도우 보안 등)의 검사 예외 설정에 패치를 풀어 둔 폴더를 추가합니다.
3. 이미 격리되었다면 백신의 격리소에서 파일을 복원한 뒤 다시 압축을 풉니다.
4. 윈도우 SmartScreen 창이 뜨면 "추가 정보" > "실행"을 선택합니다.
5. 설치가 끝난 뒤에는 예외 등록을 지우셔도 됩니다.

그래도 해결이 안 되면 게임 폴더에 생기는 `KR_패치_점검결과.txt` 파일 내용을 함께 알려 주세요.

</details>

<details>
<summary><b>릴리스 페이지의 해시와 압축을 푼 뒤 `SHA256.txt` 안의 해시가 달라요.</b></summary>

<br>

정상입니다. 두 해시는 서로 다른 파일의 값이라 같을 수가 없습니다.

- **릴리스 페이지의 해시:** 내려받은 압축 파일(`.zip`) 전체의 해시입니다. 압축 파일이 중간에 깨지지 않고 제대로 받아졌는지 확인할 때 씁니다.
- **압축 안 `SHA256.txt` 의 해시:** 압축을 푼 뒤 나오는 `TWD_KR_Patch.bat` 파일 하나의 해시입니다. 실행하기 전에 파일이 바뀌지 않았는지 확인할 때 씁니다.

확인하는 방법: 윈도우에서 명령 프롬프트를 열고 `certutil -hashfile 파일경로 SHA256` 을 입력하면 해시가 나옵니다. 압축 파일은 릴리스 페이지의 값과, `TWD_KR_Patch.bat` 는 `SHA256.txt` 의 값과 비교해 주세요.

</details>

<summary><b>게임을 켤 때 나오는 업데이트 팝업은 무엇인가요? 끄고 싶어요.</b></summary>

<br>

게임을 켤 때마다 이 저장소의 최신 버전을 확인해서, 새 패치가 있으면 다운로드할지 묻는 팝업입니다. "아니요"를 누르면 그대로 게임이 시작되고, 다음에 켤 때 다시 물어봅니다. 인터넷에 연결되어 있지 않으면 확인하지 않고 바로 게임이 시작됩니다.

끄고 싶으시면 스팀 > 게임 우클릭 > 속성 > 실행 옵션 칸에서 `KR_Launcher` 가 들어간 부분을 지우고 `%command%` 만 남기거나 칸을 비워 주세요.

</details>
